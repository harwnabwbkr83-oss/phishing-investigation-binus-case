# Phishing Investigation: Fake BINUS University Admission

## Summary
This repository documents a real phishing attempt targeting KNB Scholarship applicants for Indonesian universities, specifically impersonating BINUS University.

## Attack Vector
- Sender: binus.ac.id [spoofed] via mg.binus.ac.id
- Claim: Congratulations you got scholarship
- Goal: Steal personal data / payment

## Red Flags Found
1. Sender domain mismatch (mg.binus vs official binus.ac.id)
2. Urgent language to force click
3. Unofficial application portal link

## How to Verify Real Scholarship
Always check https://knb.kemdikbud.go.id and official university email.

## Tools Used
- Header analysis
- URLScan.io
- WHOIS lookup
